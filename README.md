**Автор:** Ощепкова Яна

## Что это
Решение тестового задания для позиции Аналитик данных. 

## Что сделано
1. **Задание 1 (Схема БД и SQL):** В файле `task1.sql` описана схема реляционной БД для онлайн-магазина (товарные группы, товары, заказы, позиции заказов). Там же написан SQL-запрос для расчета продаж помесячно.

2. **Задание 2 и 3 (Статистика и визуализация):** В файле `result.xlsx` проведен анализ данных. Я объединила события клиентов с баллами, посчитала средние баллы купивших и некупивших, сделала вывод о связи и построила столбчатую диаграмму.

## Что не сделано
- Физическая реализация БД (т.к. в задании требуется только схема и код);
- Сложные статистические тесты (достаточно описательной статистики).
